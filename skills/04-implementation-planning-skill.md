# Skill 04 - Implementation Planning

## Purpose
Sequence verifiable implementation tasks from the approved design review.

## Inputs
- Approved `docs/<story-id>/03-design-review.md`.
- Approved `docs/<story-id>/02-architecture.md`.

## Procedure
1. Confirm the design review is `approved`.
2. Convert components and accepted recommendations into small tasks (`T-n`) with target files and done conditions.
3. Order tasks by dependency and identify prerequisites.
4. Map each task to requirement and acceptance criteria IDs.
5. Define validation per task: test, command, or manual check.
6. List risks and any deferred recommendations with rationale.
7. Write `docs/<story-id>/04-impl-plan.md` and record the decision.

## Rules
- No speculative or out-of-scope tasks.
- Every acceptance criterion must be covered by at least one task and one validation.

## Output
Implementation plan artifact, ordered tasks, validation strategy, traceability matrix, and approval status.
